## Day 3 – Exploratory Data Analysis (EDA)

Performed comprehensive exploratory data analysis on mutual fund datasets and created 18 visualizations to identify trends, patterns, and investment insights.

### Key Analyses Performed

- NAV trend analysis across mutual fund schemes
- AUM growth comparison across fund houses
- Monthly SIP inflow trend analysis
- Category-wise inflow distribution
- Expense ratio comparison
- 1-Year, 3-Year, and 5-Year return analysis
- Transaction type distribution
- Buy vs Sell transaction analysis
- Top-performing schemes visualization
- Investor age-group distribution
- Benchmark performance comparison
- Fund category distribution
- State-wise investment distribution
- Daily transaction trend analysis
- AUM share distribution

### Tools & Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

### Deliverables

- `EDA_Analysis.ipynb`
- 18 PNG charts exported to `Reports/charts/`
- Key business insights documented through visual analysis

### Key Findings

1. SIP inflows showed a consistent upward trend over the analysis period.
2. A small number of fund houses contributed a significant share of total AUM.
3. Equity-oriented schemes delivered stronger long-term returns compared to short-term performance.
4. Investor participation increased steadily across multiple categories.
5. Transaction patterns highlighted dominant investment and redemption behaviors.

### Outcome

Successfully completed EDA with 18 visualizations, generating actionable insights into mutual fund performance, investor behavior, asset growth, and market trends.
